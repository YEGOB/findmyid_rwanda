🔹 1. Open XAMPP and start services
Open the XAMPP Control Panel.

Click Start for both Apache and MySQL.

🔹 2. Move your project to the htdocs folder
XAMPP runs projects from the htdocs directory. So:

🔹 4. If your project uses a database
You need to import the SQL file to MySQL:

Go to:
http://localhost/phpmyadmin

Click New → create a database (e.g., findmyid_db)

Click Import → choose your .sql file (from your project) → click Go


🔹 Step 5: Create a New Database
In phpMyAdmin, click New on the left sidebar.

Type a name for your database (e.g., findmyid_db).

Click Create.

🔹 Step 6: Import the SQL File
After creating the database, click on it in the left panel.

Click the Import tab at the top.

Click Choose File and select your .sql file (e.g., findmyid.sql).

Leave other settings as default.

Click Go at the bottom.

✔️ If your .sql file is correct, you’ll see a green success message.

✅ How to Use the FindMyID Rwanda Website
👥 Step 1: Register as a User
Go to the website:



http://localhost/id
Click on "Register" or "Create Account" (depending on your design).

Fill out the registration form:

Full Name

Email Address

Phone Number

Password

Click Submit or Sign Up.

After successful registration, you may be logged in automatically or redirected to the login page.

🔐 Step 2: Login to Your Account
Go to the Login page.

Enter your email and password.

Click Login.

You’ll be redirected to your dashboard.

🧾 Step 3: If You Found an ID
In the dashboard, click "Register Found ID".

Fill in:

Name on ID

ID Type (National ID, Passport, etc.)

ID Number

Date Found

Short Description (optional)

Click Submit.

🔍 Step 4: If You Lost Your ID
Click "Report Lost ID" or "Search for Your ID".

Fill in:

Your Full Name

Your ID Type

Your ID Number

Date Lost

Phone Number

Click Submit.
